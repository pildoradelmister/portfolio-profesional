# Portfolio profesional — Yonathan Calvo

Web estática bilingüe (español/inglés) enfocada en fútbol, análisis táctico, metodología y Big Data aplicado al rendimiento.

## Estructura

- `index.html`: portada y secciones principales.
- `assets/styles.css`: estilos responsive e identidad visual.
- `assets/script.js`: cambio de idioma y año del pie de página.

## Publicación en Cloudflare Pages

1. En Cloudflare, entra en **Workers & Pages** y crea una aplicación Pages conectada a Git.
2. Selecciona el repositorio `pildoradelmister/portfolio-profesional`.
3. Como se trata de una web estática, no necesita comando de compilación. Deja el comando de build vacío.
4. Usa ` / ` (la raíz del repositorio) como directorio de salida, sin espacios.
5. Despliega y comprueba la navegación en móvil y escritorio y el selector ES/EN.

## Independencia y privacidad

Este proyecto es independiente del repositorio `pildoradelmister/recursos`. Los vídeos no se duplican en este repositorio; permanecen en la infraestructura R2 existente. El enlace de Píldora del Míster apunta a `https://recursos.pildoradelmister.workers.dev/`.

## Antes de anunciar el portfolio

- Añadir ejemplos reales de análisis y capturas autorizadas.
- Verificar métricas y conclusiones antes de publicarlas.
- Confirmar datos de contacto, enlaces y textos en ambos idiomas.
- Revisar el acceso restringido a la biblioteca desde el sitio publicado.
